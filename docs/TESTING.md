# Testing

The project includes an automated test executable (`AudioWizardTests.exe`) generated by CMake.

## Running Tests

```bash
cmake --build build --config Debug
.\build\Debug\AudioWizardTests.exe
```

## Test Coverage

1. **Stack Tests (`testStack`):**
   - Empty state verification
   - Push and LIFO pop ordering
   - Peek / top value accuracy
   - Deep copy & move semantics
2. **LinkedList Tests (`testLinkedList`):**
   - `insertFront`, `insertBack`, `insertAt`
   - `removeFront`, `removeBack`, `removeAt`
   - `find` & `contains`
   - Pointer `reverse` logic
   - Deep copy & move semantics
3. **Queue Tests (`testQueue`):**
   - Enqueue & FIFO dequeue ordering
   - `front()` and `back()` boundary checks
   - Deep copy & move semantics
4. **Spell Mechanics (`testSpellMechanics`):**
   - Note combination recognition (`C+F+G`, `C+E+G`, `D+F+A`, `A+C+E`)
   - Mana cost verification & cooldown timers
5. **Combat & Progression (`testCombatAndProgression`):**
   - Defense mitigation damage calculations
   - Experience gain and level up stat increases
